# 「有票为证」设计稿 vs 实际小程序 —— 全屏差异清单

对照素材：`有票为证最新品牌全案设计/精修/` 11 张稿 × 小程序实机截图（微信开发者工具自动截图）
对照图：本目录 `ui-audit/拼贴主题/`（切到设计稿对应主题后）与 `ui-audit/当前线上默认(纸感)/`
版本：本地工作区 8.1.6 ｜ 线上 7.4.1

## 一、先说结论

差得远，**不是因为没照着做**——项目里 `utils/deco.js` 已经实现了邮戳、齿边纸、胶带、花枝、雏菊等 19 款装饰，`utils/theme.js` 有 6 套主题，很多屏（时光机、票根详情）**已经还原到八成了**。

真正拉开差距的是三件事：

| # | 根因 | 严重度 | 一句话 |
|---|------|--------|--------|
| 1 | **默认主题选错了** | 🔴 极高 | 设计稿是粉色手账风，线上跑的是墨黑+砖红的「纸感杂志」 |
| 2 | **字体一个都没换** | 🔴 极高 | 全项目 0 处 `loadFontFace`，标题全靠系统字体，安卓上直接掉成黑体 |
| 3 | **首页票名/日期被卡纸盖住了** | ⛔ 真 Bug | 11 张卡的票名、地点、日期、爱心用户根本看不见 |

## 二、根因 1：默认主题选错

小程序有 6 套皮肤（`utils/theme.js`），**存储为空时默认走 `paper`（纸感杂志）**：

| 令牌 | 设计稿实测 | `paper` 纸感杂志（当前默认） | `collage` 手账拼贴 |
|------|-----------|---------------------------|-------------------|
| 背景 | `#FAF4E9` | `#F5F0E6` | **`#FAF5EE`** ✅ |
| 主色 | `#DE908B`（粉） | `#2B2420`（**近黑**）❌ | **`#D9A0A6`** ✅ |
| 强调色 | `#F6DFA8`（藤黄） | `#C26B5E`（砖红） | **`#F6DFA8`** ✅ 完全一致 |
| 正文色 | `#8F7661`（暖褐） | `#2B2420`（黑） | **`#5A4D42`** ✅ |
| 次要文字 | — | `#8A7E6E` | **`#A5968A`** ✅ |

**实测**：把 `app_theme` 切成 `collage` 重截全部页面，背景纹理、粉色相机按钮、邮戳、白色撕边卡纸**立刻全部出现**——设计稿里那些"没有的东西"其实早做好了，只是没被选中。

> **动作**：改 `utils/theme.js` 的 `DEFAULT_THEME`（或首次启动时写入 `app_theme`）。**一行改动，收益最大。**
> 注意：老用户本地已存了 `app_theme`，需要一次版本迁移才能生效。

## 三、根因 2：字体完全没做

```
全项目 grep "loadFontFace" → 0 处
全项目 grep 字体文件 (.ttf/.woff/.otf) → 0 个
```

现在的写法（`app.wxss`）：

```css
--font-title: "Songti SC", "Noto Serif CJK SC", serif;   /* 想要宋体 */
--font-title: "PingFang SC", "Noto Sans CJK SC", sans-serif; /* 想要黑体 */
```

**问题**：这些**全是系统字体，且各平台不通用**——
- `Songti SC` 只有 iOS 有
- `Noto Serif CJK SC` 安卓不预装
- → **安卓用户看到的永远是系统默认黑体**，设计稿的衬线/手写感荡然无存
- → 开发工具在 Windows 上回落到 `SimSun`（中易宋体），又细又丑，跟设计稿的粗圆宋体差最远

**设计稿的字体特征**：标题是「圆润的粗衬线 / 手写体」（如「时光机」「票根收藏家」「我的 2025 时光档案」），正文是清爽黑体。

**要做的**：
1. 选 1 款标题字体 + 1 款正文字体（候选见下）
2. 字体**子集化**——中文全字库 8–15MB，必须只保留小程序里出现的字，压到 100–300KB
3. 放自己服务器（HTTPS + 小程序后台配 `downloadFile` 域名白名单）
4. 在 `app.js onLaunch` 里 `wx.loadFontFace`，按字重分别加载
5. 兜底：`font-family: "自定义", "PingFang SC", sans-serif`——加载失败也不能白屏

> ⚠️ 微信内置的 `WeChatSansStd` 只能小程序内用，**海报导出（canvas 生成分享图）用不了**，所以分享海报的字体要单独考虑。

**候选（均免费商用，按官方源下载）**：

| 用途 | 字体 | 授权 | 与设计稿的贴合度 |
|------|------|------|----------------|
| 标题首选 | 霞鹜文楷 LXGW WenKai | SIL OFL | 圆润有书卷气，最接近设计稿那种"手写感粗标题" |
| 标题备选 | 阿里妈妈方圆体 | 免费商用 | 几何圆体，更现代，但少了手写味 |
| 标题备选 | 站酷快乐体 | 站酷公益 | 最像设计稿的圆滑笔画，但偏卡通，慎用于正式场景 |
| 正文 | 思源黑体 Noto Sans SC | SIL OFL | 清爽，替代现在的苹方 |

> 最省事的办法：**去 lovart / 设计源文件里直接读字体名**（设计稿是网页字体渲染的，源文件里一定写着）。有名字再去找对应的免费替代，比盲试准得多。

## 四、根因 3：首页票名被盖住（真 Bug）

**现象**：首页每张票根卡只有照片 + 邮戳，下面一大块空白。

**实测坐标**（自动化读取元素位置）：

```
.hc-card-bg   top = 326.16   ← 不透明的白色齿边卡纸图，position:absolute; z-index:0
.hc-shot      top = 342.16   ← 照片，position:relative; z-index:2   ✅ 可见
.hc-title     top = 429.16   ← 票名，静态定位，无 z-index          ❌ 被卡纸盖住
.hc-meta      top = 451.16   ← 地点·日期·爱心，静态定位            ❌ 被卡纸盖住
```

DOM 里文本**确实存在**（`.hc-title` 文本 = "爱在南京嘉年华2026周杰伦世界巡回演唱会"），只是画在了卡纸底下。

**原因**：CSS 绘制顺序里，`position:absolute; z-index:0` 的兄弟节点画在**静态定位**内容的上面。`.hc-card-bg` 是不透明图（`pinkedPanel` 填 `#FFFDF8`），把下面两层文字整块吃掉了。

**修法**：给 `.hc-title` / `.hc-meta` / `.hc-fav` 加 `position: relative; z-index: 3;`（比卡纸的 0 高、比邮戳的 4 低即可）。

> 这一条与设计稿无关，是**已复现的界面缺陷**，建议单独先修。
> 确认范围：本地开发版（8.1.6）用自动化实测确认；线上 7.4.1 需真机再验一次（很可能同样，因为卡纸底图从「票根墙」那次提交起就是 `z-index:0`）。

**8.3.0：菜单栏「选中态=实心」**（对着截图逐枚复核后补上）

原先只把选中色换成珊瑚红，造型仍是细线 —— **漏了一条**。两份稿子其实都写明了：

| 出处 | 说法 |
|------|------|
| 稿屏02（首页） | 被选中的「票根墙」是**实心珊瑚房子**（不是细线房子） |
| 《底部Tab栏组件规范》 | 专门列了「默认态 / 选中态」两行：默认态细线，选中态**实心块面**；截图对过像素 |

改法：`icons.js` 新增 `ICON_SOLID` 表（键与 `ICON_PATH` 同名），`iconSrc` 第 5 个参数为真时优先取它；
`custom-tab-bar/index.js` 的 `icoOn` 传 `true`、`icoOff` 不传。

| 图形 | 实心版怎么来 |
|------|--------------|
| 房子 / 折页地图 | 细线版本身就是一圈闭合剪影，直接填 |
| 星形小屋 | 另有定义：整颗填实，屋里的人用 `fill-rule='evenodd'` **挖空**（细线版的人是描边，填实后会被星吞掉） |

踩过的两个坑，都记在 `icons.js` 注释里：

- 星底那个内点抠掉当「门洞」→ 34rpx 下整颗星变成三齿皇冠，认不出是星。细线版现在从缺口起笔。
- 地图实心版挖那两道折痕（2 单位宽）**渲染不出来** —— 整枚图标才 16px，折痕不到 1.5px。
  改成挖一条横贯全图的波浪带（像地图上的路线）才活得过缩放。对照实验：把挖空换成一个 r=4 的圆，
  洞是出来的，证明 `evenodd` 本身没问题，纯粹是尺寸不够。

| 差异 | 稿子 | 实际 |
|------|------|------|

**8.3.0：签到卡排版重做**（设计稿里没有这张卡，所以不是「照稿对齐」，是把我们自己这张卡里的毛病清掉）

起因：同一件事在一张卡里说了好几遍 ——「今天已收下」出现 **2 次**（标题 + 状态）、
「连签 9 天」出现 **3 次**（标题旁 + 副标题 + 状态行），而「积分怎么来」左对齐孤零零占一行，
读起来像没写完。改前六段平铺、没有主次。

| | 改前 | 改后 |
|---|------|------|
| 标题 | 「今天已收下」（状态文案当标题，跟右下角的状态撞车） | 固定「时光签」，状态交给操作行说一次 |
| 副标题 | 「已连签 9 天 · 明天再来」（连签天数第 2 遍） | 上移成主行右侧的一句话，只说「这分能干嘛」 |
| 积分 | 「积分 55」，数字 34rpx 跟在词后面 | 「**55** 积分」，数字 40rpx 打头（比标题大 1.6 倍） |
| 连签 | 23rpx 灰字，跟副标题、状态行混在一起 | 软底小胶囊「连签 **9** 天」，数字大一号 |
| 操作 | 「今天已收下」灰字 + 「兑换」**实心**按钮 + 提示各占一行 | 一行两个动作：主按钮（收下）/「今天已收下 · 明天再来」软标签，右边接**描边**的兑换 |
| 页脚 | 「积分怎么来」左对齐，像没写完 | 右对齐 + 箭头（走 `icons.js` 的 chevron，不写字符 `›`） |

结构定成**四行**（标题 / 积分 / 操作 / 页脚），`tests/checkin_layout.test.js` 13 条断言钉住：
多塞一行、把状态文案抄回标题、或者让提示再说一遍连签天数，都会红。
四种状态（未签×够兑、未签×不够、已签×够兑、已签×不够）都截图复核过。

收完结构再收**尺寸**（用户原话「做小而精致一些」）—— 排版一行没动，每一档尺寸降一号：

| | 收之前 | 收之后 |

字号之间的**级差留着**（40 / 25 / 23 / 22 / 19），内容是四行一句没少 —— 收的是尺寸，不是内容。

**8.3.1：默认头像（授权前那个）换造型**（`utils/deco.js` 的 `avatarBody()`）

授权前 / 没设过头像时，「我的」页那个圆里是这套自绘 IP。它只有 152rpx（≈73px），
`border-radius:50%` 直接裁圆，**细枝末节全糊，只有大色块和剪影能活下来**。

8.3.0 先把原来的**渔夫帽小人**修了一轮（白卫衣的尖、没脖子、帽檐厚成两只耳朵、卷发被脸吃掉），
修完形状是对的，但方向不对：稿子上整套插画都是「**水彩色块 + 极简剪影**」，
一顶渔夫帽的卡通小人是另一个路子。**8.3.1 直接换造型**，照《精修11 个人中心》
那张稿的头像抠：珊瑚渐变圆盘 + 环状头 + 穹顶身 + 一颗心 + 每侧三道光芒。

| 项 | 渔夫帽版 | 现版 |
|---|------|------|
| 底 | 无（露页面底色） | 珊瑚圆盘，主色由深到浅的横向渐变（`0.95 → 0.62`） |
| 头 | 实心肤色椭圆 + 帽子 + 五官 | **环**（描边圆，里面透出圆盘色），无五官 |
| 身 | 白卫衣，两肩峰 + 领口凹 | 光秃秃的**穹顶**，底边几乎铺满盘底（x 6.5 / 73.5） |
| 心 | 无 | 胸口一颗淡珊瑚心，9×9 单位 |
| 光芒 | 圆**外**挂 4 个 `view`（左右各两道） | 画进 SVG，每侧三道，落在**盘内** 0.75~0.9 半径处 |

比例都是量出来的（稿上圆盘直径按 245 设计px 折算），写死在代码注释里：
头环外径 = 盘径 × 0.367、圈粗 3.0 单位、环心在盘心上方 10 单位、身体穹顶顶在 y=43。

三条踩过的坑，都写进注释了：
① 渐变**必须是横向的**。写成「左上深、右下淡」的斜角，会把圆盘的左上角和右下角一起淡掉，
  圆框切出来不是整圆，是一块发糊的印子；淡的那端最低只到 0.62，再低就跟页面分不出边界。
② 光芒起点别往圆心挪。挪到 25 单位以下就贴到脸边，六道读出来是**几根胡子**。
③ **圆盘不能用主色一刀切**：`paper` / `minimal` 两套的 primary 是墨黑（#2B2420 / #1A1A1A），
  照搬会得到一颗黑盘——配暖白剪影读出来是「还没设头像」的占位黑块。主色亮度低于 90 就退到该主题的强调色，
  六套（砖红 / 藕荷 / 陶土 / 鼠尾草 / 粉 / 粉）就都是暖的了。心跟圆盘同色，否则那两套会落一颗**黑心**。
