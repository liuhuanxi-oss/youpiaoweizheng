## 二、怎么跑

```bash
cd youpiaoweizheng
npm test                 # 全部：25 套 / 659 条
npm test discover        # 只跑文件名含 discover 的那套（字符串包含，非正则、区分大小写）
npm run preview:deco     # 不开微信开发者工具，把装饰图形先渲成图看一眼
```

运行器是 `scripts/dev/run-tests.js`：

- 扫 `tests/*.test.js`，排序后**逐个起独立 node 进程**串行跑（一套崩了不影响下一套）；
- 过滤词取第一个命令行参数，匹配方式是 `文件名.includes(过滤词)`；没匹配到时提示「没有匹配的测试」并退出码 1；
- 每套自己打印 `结果：X 通过 / Y 失败`，运行器最后汇总 `测试套件：N 通过 / M 失败（共 K 套）`；
- 任一子进程退出码非 0 → 整体退出码 1，**可直接挂 CI**。

## 四、写测试的约定（新增功能照这个来）

1. **一个功能配一套**，文件名 = 功能名（`tests/xxx.test.js`），一屏一提交、一提交一套；
2. **不用 jest 等框架**：每个文件自带极简 `t(名字, fn)` + `ok(条件, 说明)`，失败即 `throw`，末尾 `process.exit(失败数 ? 1 : 0)`。零依赖、零配置，`node` 直接跑；
3. **不起微信环境**：微信小程序 API 在这里跑不起来，所以断言分两类——
   - **源文本断言**：读 `.wxml/.wxss/.js` 文本，检查类名对得上、没有 emoji、没有内联 `<svg>`、旧实现已消失；
   - **纯模块真跑**：对不依赖 `wx` 的模块（`mapArt` / `canvas-deco` / `icons` / `deco` / `poster`）真的 require 进来跑，再解析产物（data-uri、path 点、尺寸）；
4. **必须带反向断言**：只测「新东西在」不够，还要测「旧东西没了」（`!/旧类名/`）和「脏值不会崩」（注入 `undefined` / 空数组 / 字符串坐标 / 同名城市）；
5. **每条断言要能说清它防的是哪一次倒退** —— 写不清的断言，要么删掉，要么补一条注释说明来历。

## 五、它抓过的真 bug（为什么这些断言值得留）

| 问题 | 后果 | 现在的守卫 |
|---|---|---|
| WXML 用内联 `<svg>` 画图标 | 4 个 tab 图标一个都不显示 | 各套第一/二节的「不得有内联 svg / emoji」 |
| 首页收藏心读写的字段是 `_id` | 收藏心永远不亮 | `home_wall` 的「JS 里不得有 `_id`」 |
| 年报引了不存在的 `art.pm.ring` | 两枚邮戳是空的 | `annual_report` 的图形键存在性断言 |
| 气泡避让用 `toFixed` 参与坐标计算 | 字符串相加得 `"39116"`，气泡飞出屏幕 | `discover_map` 的「坐标必须是数值」 |
| 时光机的云故障横幅「数据层留着、视图层丢了」 | 用户看不见自己只看到一部分票 | `album_timemachine` 的横幅断言 |
| `pages/map` 换版后无人引用 | 页面成死页 + 勋章永远点不亮 | `page_refs` 全套（3 条） |
| WXML 绑了 JS 里不存在的处理器 | 点了没反应 | `duo_bind` 第四节的处理器存在性扫描 |
| 回忆地图的滚动容器写成 `min-height`，且没绑 `refresher-triggered` | 下拉刷新两个成因同时坏：拉不动、拉完转圈收不回 | `pull_refresh` 第三 / 二·补节（`wx.stopPullDownRefresh` 对 scroll-view 无效） |
| 详情页 / 扫描页的 `setTimeout` 没人清 | 用户提前退出，几百毫秒后又被退一层 | `scan_frame` 第十一节（定时器登记 + `onUnload` 清理） |
| 卡片保存时画布还没画完 | 存进相册的是一张空白卡 | `card_postcard` 第八节（截图前 `await _waitFirstFrame`） |
| 报告页一张票都没有也画三条 0% 的横条 | 比空态更像「数据丢了」 | `report_stats` 全套（4 条） |
| 主题页色板 `wx:key="hex"`（同一套里重复） | 控制台刷告警，还可能漏渲染一格 | `page_refs` 第二节的 wx:key 唯一性 |
