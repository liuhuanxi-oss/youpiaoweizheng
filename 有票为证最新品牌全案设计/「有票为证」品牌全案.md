# 「有票为证」品牌全案

---

## 一、品牌定位与核心价值

### 品牌定位

纸质票根数字化珍藏微信小程序——把会褪色、易丢失的纸质票，变成可永久留存、可美好分享的「数字时光档案」。

### 一句话定位

> 你的每一张票，都是一段时光的证据；有票为证，替你好好收着。

### 核心价值（三层）

| 层级 | 价值 | 说明 |
| --- | --- | --- |
| 功能价值 | AI 识别、修复、重绘 | 一键让模糊/破损/褪色的票根清晰重生，自动归档分类 |
| 情感价值 | 收藏的不是票，是记忆 | 收藏的是和某个人、在某个夜晚的自己——把「舍不得扔」变成「存得好看」 |
| 社交价值 | 私人记忆 → 可分享数字票卡 | 让「我去过、我爱过、我在场」被温柔地看见 |

### 品牌角色

一个温柔、细心、有点文艺的「时光收票员」——不打扰、懂纪念、帮你把回忆理成一本好看的册子。

## 三、品牌命名与 Slogan

### 品牌名：有票为证

「有 X 为证」是中国人熟悉的立证句式，天然带仪式感与可信度；「票」直接点出品类；四字平仄顺口，适合做字标与口碑传播。

### Slogan

> **时光不回头，票根存温柔**

上句讲遗憾与不可逆，下句给解法与慰藉；「存温柔」三字把工具行为升华为情感动作。

### 辅助传播语（备选）

- 把票根，存成时光
- 走过的，都有票为证
- 我在场，故我在

## 四、品牌故事与调性

### 品牌故事（简版）

我们都有一沓舍不得扔的票：第一次看演唱会那晚、两个人的第一场电影、说走就走的那张车票。纸会黄、字会淡，可记忆不该。有票为证想做的，是给每一张票一个温柔的归处——拍下来，修复它，重绘它，让那一夜的光，一直亮着。时光不回头，但我们可以，为它留证。

### 品牌调性

- **关键词**：温暖治愈 · 年轻文艺 · 仪式感 · 柔软可信
- **语气原则**：像朋友轻声说话，多用「你/我们」，少用功能腔；可以怀旧但不丧，可以可爱但不幼稚。

## 五、视觉识别系统（VIS）

### 1. Logo——珍藏票夹（已锁定）

两张圆角票根轻叠，负形合成一颗心 / 一枚珍藏信封，顶部一点微光。

- 双票 = 「与某个人、某段经历」
- 心形 = 温柔
- 星光 = 被点亮的记忆

含 App 图标、横版组合、反白 / 单色 / 小尺寸全套变体。

### 2. 标准色

| 色名 | HEX | 角色 |
| --- | --- | --- |
| 奶油白 | `#FAF5EE` | 主背景 |
| 蜜桃粉 | `#F4C6B4` | 品牌主色 / 主按钮 |
| 鹅黄 | `#F6DFA8` | 暖光点缀 |
| 灰玫粉 | `#D9A0A6` | 辅助 / 强调 |
| 鼠尾草绿 | `#A9C3A6` | 分类 / 平衡色 |
| 暖褐灰 | `#6B5B50` | 文字 / 单色标 |
| 褪色邮政红 | `#C26B5E` | 票根身份点缀（克制使用） |

### 3. 字体

中文采用圆润现代的人文无衬线（标题偏饱满、正文高可读），气质友好文艺；西文与数字搭配圆润几何体，用于日期、编号。标题 / 正文 / 标注三级层级。

### 4. 辅助图形

票根齿孔点列、邮戳圆环、日期印章、序列号、波浪销票线、微光星点、虚线路径——统一用灰玫 / 暖褐灰细线呈现，作为品牌的「时光档案」视觉语汇。

### 5. 图像与质感

奶油纸感 + 明亮柔和日光 + 圆角卡片 + 大留白；真实物料保持纸质与印刷质感，界面保持原生控件层级，不把一切都卡通化。

## 六、应用物料规范（已出视觉稿）

### 小程序

- **档案墙**：票卡瀑布流 + 分类
- **详情时光卡**：修复后票根 + 邮戳日期 + 分享
- **拍照上传**：取景对齐 + 识别 → 修复 → 重绘 → 入档

### 社媒模板

- 小红书封面
- 数字票根分享海报（含二维码位）
- 朋友圈方形分享卡

### 实体周边

纪念票卡（齿孔 + 编号 + 邮戳烫印）、贴纸、明信片——延续可触摸的仪式感。

### 使用红线

- 主标识不得拉伸 / 改色 / 旋转 / 加阴影
- 辅助图形不得喧宾夺主
- 邮政红只作小面积点缀

## 七、品牌传播与落地建议

### 冷启动 · 内容种草

以「晒你的第一张票根」UGC 话题切入小红书 / 抖音，主打前后修复对比 + 情绪故事。

### 节点营销

情人节（我们的第 N 张票）、毕业季、跨年演唱会、电影节——把票根变成节点仪式。

### 裂变机制

数字票卡自带「有票为证」水印与小程序码，分享即拉新；情侣 / 好友「共同票夹」促留存。

### 线下联动

与 Livehouse、影院、文创书店合作设「票根寄存点」，扫码即可入档，线上线下闭环。

### 产品节奏

先做好「修复 + 归档 + 分享卡」核心闭环，再逐步开放年度时光册、实体票卡定制等增值。
